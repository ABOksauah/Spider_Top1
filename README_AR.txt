RG MOD - لوحة إدارة الأكواد واللودرات
====================================

المحتويات:
- database.sql : جداول قاعدة البيانات التجريبية.
- config.php : إعداد اتصال MySQL.
- install.php : إنشاء حساب المدير الأول (احذف الملف بعد نجاح الإعداد).
- login.php / logout.php : تسجيل الدخول والخروج.
- index.php : لوحة الإحصائيات وإدارة الأكواد واللودرات.
- action.php : إجراءات إضافة/تعطيل/حذف الأكواد واللودرات.
- style.css : تصميم داكن أزرق متجاوب للهاتف.
- .htaccess : حماية بعض الملفات على خوادم Apache.

التثبيت على InfinityFree:
1) من لوحة InfinityFree افتح File Manager ثم مجلد htdocs.
2) ارفع محتويات مجلد rgmod_admin_panel إلى htdocs (لا ترفع المجلد نفسه إذا تريد أن يفتح النطاق مباشرة).
3) افتح MySQL Databases وأنشئ قاعدة بيانات، ثم افتح phpMyAdmin واضغط Import واستورد database.sql.
4) افتح config.php وعدّل DB_HOST وDB_NAME وDB_USER وDB_PASS حسب بيانات MySQL المعروضة في لوحة الاستضافة. استخدم اسم قاعدة البيانات الكامل مع البادئة.
5) افتح https://YOUR-DOMAIN/install.php وأنشئ حساب المدير. اختَر كلمة مرور قوية.
6) بعد نجاح إنشاء المدير، احذف install.php من htdocs.
7) افتح https://YOUR-DOMAIN/login.php وسجّل الدخول.

ملاحظات مهمة:
- لا تستخدم بيانات قاعدة البيانات أو كلمة مرور المدير التي تظهر في أمثلة على الإنترنت.
- لا تشارك config.php أو بيانات الاستضافة مع أي شخص.
- هذه لوحة أولية، لا ترفع ملفات APK/PHP مجهولة أو ملفات غير موثوقة.
- قسم اللودرات يسجّل اسم اللودر ورابط تنزيله ووصفه وحالته. لا يشغّل الملفات على الخادم.
- رفع الملفات مباشرة غير مفعّل في هذه النسخة لتقليل مخاطر رفع ملفات ضارة؛ يمكنك وضع ملفك المصرّح به في خدمة تنزيل موثوقة وإضافة رابطه في اللوحة.
